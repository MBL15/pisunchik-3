# 6. UI и дизайн-система

Серверный рендер Jinja2 + Tailwind CSS (CDN), ванильный JS без сборки. Визуальный язык повторяет
[fsp-russia.ru](https://fsp-russia.ru/): тёмный графит, фирменный синий, моноширинные заголовки,
«чертёжные» линии, жёсткие тени при наведении. Поверх него — интерактивный «вау-слой».

## Где что лежит

Шлюз: `main.py` — приложение, обработчики ошибок, публичные страницы, кабинеты и их действия; `web.py` — общий слой
(клиенты сервисов, шаблоны и фильтры, `current_user`/`require`/`render`/`back`, выгрузки, адресаты уведомлений);
`routes/` — разделы со своими маршрутами (`registry`, `moderation`, `audit`, `notifications`); `listing_ui.py` — состояние
списков в адресе.

| Файл | Содержимое |
|---|---|
| `templates/base.html` | `tailwind.config` с токенами `fsp-*`, шапка-остров, flash, футер, **весь общий JS** |
| `static/app.css` | Эффекты (spotlight, beam, reveal, кольца, конфетти-совместимые анимации), печать, reduced-motion |
| `templates/macros.html` | Классы-токены (`BTN`, `CARD`, `INPUT`…), иконки, бейджи, заголовки, навигация кабинета |
| `templates/_cabinet_head.html` | Шапка профиля, общая для всех кабинетов |
| `templates/_live_protocol.html`, `_rating_table.html` | Переиспользуемые фрагменты |

## Система эффектов (data-атрибуты)

Весь JS — в конце `base.html`, работает по атрибутам, поэтому эффект подключается разметкой без нового кода.

| Атрибут / класс | Эффект |
|---|---|
| `data-reveal` (`""`, `left`, `scale`) | Появление при прокрутке; после показа атрибут снимается, чтобы не мешать hover-трансформам |
| `data-stagger` (`""`, `left`, `scale`) | Дети контейнера появляются по очереди (шаг 80 мс) |
| `data-count="N"` | Счётчик 0 → N (только для целых) |
| `data-scramble="текст"` | «Расшифровка» заголовка с фирменной вспышкой |
| `data-type="текст"` | Печатающийся текст |
| `data-bar` | Полоска растёт до своей ширины, когда предок получил `.is-in` (нужен предок с `data-reveal`/`data-stagger`) |
| `canvas[data-network]` | Сеть узлов, тянется к курсору; пауза вне экрана и в фоне |
| `data-parallax-root` + `data-parallax="0.04"` | Параллакс от курсора |
| `data-progress` | Линия прогресса прокрутки в шапке |
| `data-spy` (в `cabinet_nav`) | Ползунок активного раздела, `aria-current` |
| `data-copy="текст"` + `data-copy-label` | Копирование в буфер с подтверждением |
| `data-celebrate` (на flash) | Конфетти из `.just-added` или из flash |
| `data-live-src` | Опрос HTML-фрагмента live-протокола |
| `data-toggle="id"` | Раскрытие строки (разбор рейтинга) |
| `data-options-source` | Зависимый select (справки в кабинете федерации) |
| `.spotlight` | Подсветка карточки и её рамки за курсором |
| `.beam` / `.beam-light` | Световой блик, бегущий по рамке (родителю нужен `position: relative`) |
| `.step-live` | Световая волна по текущему шагу трекера заявки |
| `.just-added` | Свечение только что созданной записи |
| `.rail-draw` | Линия, прорисовывающаяся при появлении |
| `.ticker`, `.trace`, `.node-pulse`, `.caret` | Бегущие строки, «дорожки» платы, пульс узлов, курсор |

### Обязательные правила для эффектов

- **Без JS всё видно**: скрытие (`opacity: 0`) применяется только под `.js` на `<html>`.
- **`prefers-reduced-motion`**: анимации и переходы отключаются в `app.css`, JS сразу показывает финальное состояние,
  конфетти не запускаются, canvas не анимируется.
- **Декор скрыт от скринридеров**: `aria-hidden="true"` на canvas, бликах, индикаторах; у заголовка со
  scramble есть `aria-label`, у кольца срока — `sr-only` текст.
- **Hover не сдвигает раскладку**: используем тени, цвет, `translate` самого элемента.
- Не называйте свои классы именами утилит Tailwind (пример бага: `.ring` дал синюю рамку, класс переименован
  в `.cd-ring`).
- Headless Chrome троттлит `requestAnimationFrame`, поэтому у scramble и счётчиков есть таймер-страховка.

## Кабинеты

Структура кабинета: `_cabinet_head.html` → `cabinet_nav` → разделы `<section id=… class="scroll-mt-36">`
с `step_head("01", …)`. Счётчики навигации считают только то, что требует действия
(например, у тренера не считаются подопечные, по которым заявка уже подана).

Кабинет федерации — с вкладками (`nav[aria-label="Вкладки кабинета"]`, `?tab=`): шлюз грузит общие данные для меток
(дашборд, календарь, заявки на квалификацию, ЕВСК) и только данные активной вкладки; `cabinet_nav` под вкладками —
разделы текущей вкладки. Соответствие «раздел → вкладка» — `ADMIN_SECTIONS` в `gateway_service/main.py`; оно же
передаётся в страницу для перевода старых якорных ссылок. Новый раздел: добавьте его в `ADMIN_SECTIONS`, в нужную
ветку `{% if tab == … %}` шаблона и в `cabinet_nav` этой вкладки; редиректы действий — через `admin_url("раздел")`.

Графики (инфографика кабинета министерства): серверный SVG без библиотек. Геометрию (шкала, столбцы, линия, дуги кольца) считает
`gateway_service/infographic.py`, шаблон `_ministry_infographic.html` только рисует (макросы `combo`, `hbars`); цвета — hex токенов ФСП
(`#402FFF`, `#8C80FF`, сетка `#3D3E42`). Анимации `.chart-bar` / `.chart-line` / `.chart-arc` — в `static/app.css`, при
`prefers-reduced-motion` отключены. Цвет не единственный носитель смысла: у долей есть подписи и проценты, у графиков — `role="img"` со значениями.

Шапка профиля: сеть узлов, свечение с параллаксом, beam по рамке, вращающееся кольцо аватара,
ФИО со scramble, ФСП ID с копированием, дисциплины, кольца обратного отсчёта для разряда и судейской
категории, мобильный переключатель ролей.

## Удобство: интерактивный тур и общие приёмы

**Тур** (`static/tour.js`, шаги — `gateway_service/tours.py`) — необязательные подсказки, которые подсвечивают настоящие элементы страницы
и объясняют их по порядку. У каждой страницы свой тур (лендинг, календарь, рейтинг, регистрация, четыре кабинета, сборные, отчёт,
протокол); состав зависит от роли и гостя. Шаг — `{sel, title, text}`; если элемента нет на странице (скрыт на узком экране, нет данных),
шаг пропускается. Чтобы добавить шаг, допишите его в `tours.py`; новая страница — функция-построитель и строка в `for_page`.

- **Не навязывается:** впервые на странице показывается карточка «Впервые здесь?» с кнопками «Показать тур», «Не сейчас» и «Больше не
  предлагать». Тур запускается кнопкой «?» (внизу справа) или клавишей «?» в любой момент; конец цепочки ведёт к следующему туру (`?tour=1`).
- **Состояние** — `localStorage`, ключ `fsp.tour:<ФСП ID|guest>`: `done` / `offered` по id тура. «Больше не предлагать» хранится на весь браузер (`fsp.tour:muted` и cookie `fsp_tour_muted`, 1 год), поэтому не возвращается при входе под другим демо-аккаунтом; без хранилища тур предлагается снова.
- **Управление:** «Далее» / «Назад» / «Пропустить тур», ← → Esc; фокус остаётся в диалоге и возвращается на кнопку «?».
  Подсветка — `box-shadow` вокруг «окна»; `prefers-reduced-motion` отключает анимации.
- **На телефоне (< 640 px) тура нет:** `tour.js` не показывает кнопку «Подсказки», окно «Впервые здесь?», клавишу «?» и адрес `?tour=1`; при сужении окна до телефона открытый тур закрывается, при расширении кнопка возвращается.
- Данные тура вставляет `base.html` (`<script id="tour-data" type="application/json">`, фильтр `tojson_script` экранирует `<`).

**Специальные возможности** (кнопка с фигуркой в шапке на каждой странице, `Alt+Shift+A`, а также «Настройки специальных возможностей» первой после ссылки «Перейти к содержимому»).
Панель `#a11y-panel` (`_a11y_panel.html`) — модальный `<dialog>`; логика в `static/a11y.js`, оформление режимов в `static/a11y.css`. Настройки лежат в `localStorage['fsp.a11y']` и применяются
атрибутами `<html data-a11y-*>`; ранний скрипт в `<head>` ставит их до первой отрисовки, поэтому схема не мигает. Без сохранённого выбора при системном `prefers-contrast: more` включается «Белое на чёрном».

| Группа | Что есть | Как устроено |
|---|---|---|
| Быстрые профили | слабовидящим · незрячим (экранный диктор) · дислексия · трудно попадать мышью · раздражает движение | набор значений из `PRESETS` в `a11y.js`, сбрасывает остальное |
| Размер текста | 100 / 125 / 150 / 175 % | `font-size` корня масштабирует всё в rem, мелкие подписи `text-[10–17px]` — через `--a11y-k`; шапка при крупном тексте переносится |
| Цветовая схема | обычная · чёрное на белом · белое на чёрном · жёлтое на чёрном | Tailwind-цвета `fsp-*` берутся из переменных `--c-*` (`rgb(var(--c-bg) / <alpha-value>)`), схема подменяет переменные; «чёрное на белом» — белая схема с `filter: invert(1) hue-rotate(180deg)` на `<html>`, поэтому яркие акценты палитры сами становятся тёмными |
| Шрифт и интервалы | простой шрифт (Verdana) · интервалы по WCAG 1.4.12 | подмена `font-family`, `letter-spacing`, `word-spacing`, `line-height` |
| Управление | подчёркивание ссылок · яркая рамка фокуса · крупный курсор · крупные кнопки и поля | отдельные переключатели; в контрастных схемах рамка фокуса включена всегда |
| Спокойный режим | без анимации, движения, декоративных сеток и свечения | CSS отключает `animation`/`transition`, а `reduce` в скрипте эффектов (набор заголовка, счётчики, конфетти, сеть узлов) читает `data-a11y-calm` как `prefers-reduced-motion` |
| Режим для экранного диктора | включает спокойный режим; живые таблицы не перерисовываются сами — вместо этого кнопка «Обновить таблицу» с объявлением времени; тур-подсказка не всплывает | `data-a11y-sr` читают `base.html` (опрос `/partials/live`) и `tour.js` |
| Озвучивание | «Читать страницу», «Читать выделенное», «Остановить», скорость речи, название элемента при Tab | Web Speech API (`ru-RU`), текст режется на фразы до ~220 знаков; если браузер не умеет — кнопки недоступны и показано пояснение |

**Вернуть по умолчанию**: кнопка закреплена в нижней части панели (не прокручивается вместе с настройками) и неактивна, пока менять нечего; под ней подпись о состоянии. Сброс (`reset()` в `a11y.js`) удаляет `localStorage['fsp.a11y']` целиком, а не записывает значения по умолчанию, поэтому состояние то же, что при первом заходе: размер 100 %, обычная схема, фирменный шрифт, все режимы выключены, скорость речи 1,0×, остановлено озвучивание; при системном `prefers-contrast: more` вернётся «Белое на чёрном» — ту же исходную точку считает `initial()` в скрипте и ранний скрипт в `base.html`. Открытые вкладки подхватывают сброс через событие `storage`.

Новая настройка: ключ в `DEFAULTS` и (если нужно) `PRESETS` в `a11y.js`, правила `html[data-a11y-<ключ>="…"]` в `a11y.css`, вариант в `_a11y_panel.html`. Согласованность проверяет `tests/test_a11y.py`
(в т.ч. запасные цвета Tailwind-конфига против `:root`, и то, что псевдоэлемент не попал в `:is()` — такой селектор молча не работает).

**Поиск функции или параметра в кабинете** (`[data-finder]` в `_cabinet_head.html`, у всех пяти ролей под карточкой профиля). Поле «Найти функцию или параметр» понимает
обычные слова: «допинг», «продлить приём», «выгрузка xlsx», «коэффициент». Каталог активной роли лежит в `gateway_service/cabinet_search.py` (`entries(role, telegram)`:
название, подсказка, адрес, ключевые слова, «где находится», показывать ли до набора) и выводится скрытым списком `role=listbox`; `ux.js` фильтрует его по основам слов
(«заявки» находят «заявка»), показывает до 8 результатов, на пустом запросе — отмеченные `top`. Управление: набор, ↑ ↓, Enter, Esc, `Ctrl K` (или «/» на странице без
собственного `[data-search]`). Якорь на той же странице и вкладке — плавная прокрутка и подсветка раздела; иначе обычный переход, подсветка срабатывает на новой странице
(`sessionStorage`, ключ `fsp.finder:flash`). Новая функция кабинета: строка в нужной роли каталога; якорь обязан существовать в шаблоне роли, а адрес федерации — вести на вкладку
из `ADMIN_SECTIONS` — это проверяет `tests/test_cabinet_search.py`.

**Общие приёмы** (`static/ux.js`): `data-confirm="…"` (+ `data-confirm-label`) на форме или кнопке — подтверждение необратимых действий в `<dialog>`
(по умолчанию в фокусе «Отмена»); кнопки формы блокируются при отправке и показывают индикатор (защита от двойного нажатия);
сообщения `[OK]`/`[ERR]` закрываются крестиком; панель выбора в сборную на `/rating` (`data-pick-bar`: «Первые 5/10», «Сбросить», счётчик).
Малые кнопки (`BTN_SM`/`BTN_OK`/`BTN_NO`) на сенсорных экранах не ниже 44 px. В кабинете федерации сверху — полоса «Быстрые действия».

## Адаптация под телефоны и планшеты

Брейкпоинты Tailwind: телефон `< sm` (640), планшет `sm`–`lg`, меню-«бургер» до `xl` (1280). Общие правила — в конце `static/app.css`, поведение — в конце `static/ux.js`.

- **Шапка на ноутбуках (1280–1440 px)**: у мультиролевого администратора правая группа самая широкая, поэтому подпись «федерация спортивного программирования» у логотипа скрыта с `xl`, а ФСП ID в кнопке «Кабинет» показывается с 1440 px; кнопка не переносится (`whitespace-nowrap shrink-0`). Проверка: iframe 1280/1366/1440/1920 px, `scrollWidth` не больше ширины окна, высота кнопки «Кабинет» ≈ 34 px.
- **Меню шапки** (`base.html`, `details[data-menu]`): панель на всю ширину острова (на планшете — 30rem в две колонки): карточка пользователя, «Разделы», «Ещё», переключатель роли, «Выйти» (на телефоне кнопка выхода живёт здесь), для гостя — «Войти / Регистрация». Закрывается по Esc, касанию вне панели и переходу; открытое меню прячет подсказки тура.
- **Таблицы-карточки**: `<table class="cards …">` на экранах `< lg` превращает строки в карточки. Подписи ячеек `ux.js` берёт из `thead`; роль ячейки задаёт `data-card`: `lead` (чекбокс, место), `title` (имя), `full`, `actions` (кнопки, отделены пунктиром), `expand` (кнопка раскрытия; подпись — `data-card-text`). Без `data-card` первая ячейка — `title`, остальные — плитки «подпись / значение» (2 в ряд на телефоне, 4 на планшете). Включено в рейтинге, реестре, заявках, сборной, нормативах, кабинетах спортсмена/тренера. Остальные широкие таблицы просто прокручиваются (`.overflow-x-auto`) с затуханием у скрытого края (`data-fade`).
- **Страховки от переполнения**: `.grid > *` и `main section/form` — `min-width: 0`; `select/input` — `max-width: 100%`; у `.overflow-x-auto` — `position: relative` (иначе `sr-only`-подписи внутри таблицы раздвигают страницу).
- **Сенсорные экраны**: поля ввода 16px (iOS не увеличивает страницу), цели нажатия ≥ 44px, чекбоксы 22px, `viewport-fit=cover` и отступы под вырезы.
- Новую широкую таблицу: добавьте `cards`, у ячеек-«шапки» строки — `data-card`; проверьте при 375 и 768 px (iframe или CDP `Emulation.setDeviceMetricsOverride`) и что `document.documentElement.scrollWidth` не больше ширины окна.

## Большие списки

Общий подход для реестра, модерации заявок, журнала, календаря и ленты: фильтрация, сортировка и страницы — на сервере
(`shared/listing.py`: поиск по словам без учёта регистра и «ё», `page()`, `facets()`), состояние — в адресе (можно
поделиться ссылкой, «назад» работает).

- `gateway_service/listing_ui.py`: `qs(request, **изменения)` (глобальная функция шаблонов: текущий адрес с изменёнными
  параметрами; пустое значение убирает параметр, любой фильтр сбрасывает номер страницы), `pages(result)`,
  `list_args(request, …)`, `chips(request, filters, labels, defaults)` → чипы и адрес «сбросить всё».
- Номер страницы за последней приводит к последней странице прямо в `shared/listing.page()` (`clamp_offset`),
  поэтому маршрутам ничего досчитывать не нужно.
- Макросы: `pager(p, request)` (номера с окном, «показано 1–50 из N», размер страницы 25/50/100/200),
  `sort_th(label, key, request, sort, order)` (`aria-sort`), `filter_chips(chips, reset)`, `search_box(value, placeholder, id)`,
  `facet_option(value, label, current, facet)` — вариант фильтра со счётчиком (нули приглушены).
- Форма с массовыми действиями начинается с отключённой скрытой кнопки `submit`: Enter в текстовом поле не отправляет
  форму первой «настоящей» кнопкой (например, «Одобрить отмеченные»).
- `form[data-autosubmit]` — списки и флажки применяются сразу, поиск — через 450 мс паузы; пустые поля не попадают
  в адрес; фокус и курсор восстанавливаются после перезагрузки. «/» — к поиску, Esc — очистить.
- На телефоне поля с классом `.fsp-more` свёрнуты под кнопку «Фильтры · N» (`[data-filters-toggle]`, правило в `app.css`).
- Рядом со значением фильтра — сколько записей найдётся (фасет без собственного фильтра); значения в ячейках таблиц —
  ссылки «показать только это» (организация, муниципалитет, дисциплина, автор в журнале).
- `[data-filter-input]` — мгновенный фильтр по уже загруженному списку (рейтинг, подопечные тренера);
  `[data-option-filter]` — поиск внутри длинного `<select>` (назначение судей).
- `[data-bulk]` — массовый выбор: `[data-bulk-item]`, «все на странице» `[data-bulk-all]`, Shift — диапазон,
  счётчик `[data-bulk-count]`, кнопки `[data-bulk-action]` активны только при выборе.
- Таблицы — в контейнере `max-h-[72vh] overflow-auto` с закреплённой шапкой; панель фильтров закреплена на `lg+`.

## Особенности Jinja и Starlette

- Starlette 1.0: `templates.TemplateResponse(request, name, context)` — `request` первым аргументом.
- Макросы, которые используются внутри дочернего шаблона, должны быть определены **внутри `{% block %}`**
  (пример — `assignment()` в `cabinet_judge.html`).
- Фильтры шлюза: `ru_date` (`|ru_date`, `long=True`), `ru_mon`, `days_word`; глобальные `plural(n, …)`, `D`,
  фильтр `tojson_ru` для JSON с кириллицей.
- Тексты, на которые завязаны e2e-проверки (`DEMO_ACCOUNTS[].check`), менять только вместе с `demo_roster.py`.

## Лендинг и команды

- Синяя полоса с тремя числами на главной: каждая ячейка — ссылка (подпись `<a>` растянута на всю ячейку через `after:absolute after:inset-0`, число остаётся `<dd>`): спортсменов → `/registry` (у федерации) или `/rating`, соревнований → `/calendar`, дисциплин → `#disciplines`. Hover подсвечивает ячейку, фокус с клавиатуры — рамка.
- `/squads` (`squads.html`): блок «Вас приглашают» (карточка с рамкой-акцентом, как запрос тренера), форма «Создать команду», фильтр по дисциплине и названию, карточки команд с составом, приглашёнными и действиями по роли (капитан, участник, федерация). Подтверждения — `confirm()` на исключении, выходе и роспуске.
- Карточка «Мои дисциплины» в кабинете спортсмена (`#disciplines`): шесть переключателей-плиток как в регистрации, командные подписаны.

## Вход и выход (аудит пути)

- Кнопка «Выйти» в шапке: иконка + подпись (на `sm+`), цель касания 44 px; после выхода — flash на главной.
- Форма регистрации без `novalidate`: браузер подсвечивает поле на месте, серверные ошибки — плашкой сверху.
- В шапке кабинета — «Подключить Telegram» / «Telegram подключён · Отключить» (`_cabinet_head.html`).
- В шапке сайта у вошедшего — колокольчик (`icon("bell")`) со счётчиком новых → `/notifications`; у федерации в меню — «Реестр».
- Основное меню шапки показывается с `xl` (1280 px), ниже — бургер: у федерации с двумя ролями шапка не помещалась в 1024 px.
