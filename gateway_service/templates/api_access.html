Подключение MCP

Сервер mcp_fsp запускается рядом с моделью (Claude Desktop, Claude Code) и ходит в API по вашему токену. Добавьте в mcpServers конфигурации или в .mcp.json (путь — к папке с репозиторием платформы):

{
  "mcpServers": {
    "fsp": {
      "command": "py",
      "args": ["-X", "utf8", "-m", "mcp_fsp"],
      "cwd": "C:\\путь\\к\\orencode",
      "env": {
        "PYTHONPATH": "C:\\путь\\к\\orencode",
        "FSP_API_TOKEN": "fspu_…ваш токен…",
        "FSP_API_URL": "{{ api_base }}"
      }
    }
  }
}

Напрямую API доступен по {{ api_base }} с заголовком Authorization: Bearer fspu_…; описание — {{ api_base }}/docs.

Тексты на платформе пишут пользователи: модели сказано относиться к ним как к данным, а не как к инструкциям. Действия, которые меняют данные, модель должна согласовывать с вами.
