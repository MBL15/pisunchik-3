# 6. UI и дизайн-система

Серверный рендер Jinja2 + Tailwind CSS (CDN), ванильный JS без сборки. Визуальный язык повторяет
[fsp-russia.ru](https://fsp-russia.ru/): тёмный графит, фирменный синий, моноширинные заголовки,
«чертёжные» линии, жёсткие тени при наведении. Поверх него — интерактивный «вау-слой».

## Где что лежит

Шлюз: `main.py` — приложение, обработчики ошибок, публичные страницы, кабинеты и их действия; `web.py` — общий слой
(клиенты сервисов, шаблоны и фильтры, `current_user`/`require`/`render`/`back`, выгрузки, адресаты уведомлений);
`routes/` — разделы со своими маршрутами (`registry`, `moderation`, `audit`, `notifications`); `listing_ui.py` — состояние
списков в адресе.

| Файл | Содержимое |
|---|---|
| `templates/base.html` | `tailwind.config` с токенами `fsp-*`, шапка-остров, flash, футер, **весь общий JS** |
| `static/app.css` | Эффекты (spotlight, beam, reveal, кольца, конфетти-совместимые анимации), печать, reduced-motion |
| `templates/macros.html` | Классы-токены (`BTN`, `CARD`, `INPUT`…), иконки, бейджи, заголовки, навигация кабинета |
| `templates/_cabinet_head.html` | Шапка профиля, общая для всех кабинетов |
| `templates/_live_protocol.html`, `_rating_table.html` | Переиспользуемые фрагменты |

## Система эффектов (data-атрибуты)

Весь JS — в конце `base.html`, работает по атрибутам, поэтому эффект подключается разметкой без нового кода.

| Атрибут / класс | Эффект |
|---|---|
| `data-reveal` (`""`, `left`, `scale`) | Появление при прокрутке; после показа атрибут снимается, чтобы не мешать hover-трансформам |
| `data-stagger` (`""`, `left`, `scale`) | Дети контейнера появляются по очереди (шаг 80 мс) |
| `data-count="N"` | Счётчик 0 → N (только для целых) |
| `data-scramble="текст"` | «Расшифровка» заголовка с фирменной вспышкой |
| `data-type="текст"` | Печатающийся текст |
| `data-bar` | Полоска растёт до своей ширины, когда предок получил `.is-in` (нужен предок с `data-reveal`/`data-stagger`) |
| `canvas[data-network]` | Сеть узлов, тянется к курсору; пауза вне экрана и в фоне |
| `data-parallax-root` + `data-parallax="0.04"` | Параллакс от курсора |
| `data-progress` | Линия прогресса прокрутки в шапке |
| `data-spy` (в `cabinet_nav`) | Ползунок активного раздела, `aria-current` |
| `data-copy="текст"` + `data-copy-label` | Копирование в буфер с подтверждением |
| `data-celebrate` (на flash) | Конфетти из `.just-added` или из flash |
| `data-live-src` | Опрос HTML-фрагмента live-протокола |
| `data-toggle="id"` | Раскрытие строки (разбор рейтинга) |
| `data-options-source` | Зависимый select (справки в кабинете федерации) |
| `.spotlight` | Подсветка карточки и её рамки за курсором |
| `.beam` / `.beam-light` | Световой блик, бегущий по рамке (родителю нужен `position: relative`) |
| `.step-live` | Световая волна по текущему шагу трекера заявки |
| `.just-added` | Свечение только что созданной записи |
| `.rail-draw` | Линия, прорисовывающаяся при появлении |
| `.ticker`, `.trace`, `.node-pulse`, `.caret` | Бегущие строки, «дорожки» платы, пульс узлов, курсор |

### Обязательные правила для эффектов

- **Без JS всё видно**: скрытие (`opacity: 0`) применяется только под `.js` на `<html>`.
- **`prefers-reduced-motion`**: анимации и переходы отключаются в `app.css`, JS сразу показывает финальное состояние,
  конфетти не запускаются, canvas не анимируется.
- **Декор скрыт от скринридеров**: `aria-hidden="true"` на canvas, бликах, индикаторах; у заголовка со
  scramble есть `aria-label`, у кольца срока — `sr-only` текст.
- **Hover не сдвигает раскладку**: используем тени, цвет, `translate` самого элемента.
- Не называйте свои классы именами утилит Tailwind (пример бага: `.ring` дал синюю рамку, класс переименован
  в `.cd-ring`).
- Headless Chrome троттлит `requestAnimationFrame`, поэтому у scramble и счётчиков есть таймер-страховка.

## Кабинеты

Структура кабинета: `_cabinet_head.html` → `cabinet_nav` → разделы `<section id=… class="scroll-mt-36">`
с `step_head("01", …)`. Счётчики навигации считают только то, что требует действия
(например, у тренера не считаются подопечные, по которым заявка уже подана).

Шапка профиля: сеть узлов, свечение с параллаксом, beam по рамке, вращающееся кольцо аватара,
ФИО со scramble, ФСП ID с копированием, дисциплины, кольца обратного отсчёта для разряда и судейской
категории, мобильный переключатель ролей.

## Удобство: интерактивный тур и общие приёмы

**Тур** (`static/tour.js`, шаги — `gateway_service/tours.py`) — необязательные подсказки, которые подсвечивают настоящие элементы страницы
и объясняют их по порядку. У каждой страницы свой тур (лендинг, календарь, рейтинг, регистрация, четыре кабинета, сборные, отчёт,
протокол); состав зависит от роли и гостя. Шаг — `{sel, title, text}`; если элемента нет на странице (скрыт на узком экране, нет данных),
шаг пропускается. Чтобы добавить шаг, допишите его в `tours.py`; новая страница — функция-построитель и строка в `for_page`.

- **Не навязывается:** впервые на странице показывается карточка «Впервые здесь?» с кнопками «Показать тур», «Не сейчас» и «Больше не
  предлагать». Тур запускается кнопкой «?» (внизу справа) или клавишей «?» в любой момент; конец цепочки ведёт к следующему туру (`?tour=1`).
- **Состояние** — `localStorage`, ключ `fsp.tour:<ФСП ID|guest>`: `done` / `offered` по id тура и общий `muted`; без хранилища тур предлагается снова.
- **Управление:** «Далее» / «Назад» / «Пропустить тур», ← → Esc; фокус остаётся в диалоге и возвращается на кнопку «?».
  Подсветка — `box-shadow` вокруг «окна»; на узком экране подсказка — нижняя панель, цель прокручивается выше неё; `prefers-reduced-motion` отключает анимации.
- Данные тура вставляет `base.html` (`<script id="tour-data" type="application/json">`, фильтр `tojson_script` экранирует `<`).

**Общие приёмы** (`static/ux.js`): `data-confirm="…"` (+ `data-confirm-label`) на форме или кнопке — подтверждение необратимых действий в `<dialog>`
(по умолчанию в фокусе «Отмена»); кнопки формы блокируются при отправке и показывают индикатор (защита от двойного нажатия);
сообщения `[OK]`/`[ERR]` закрываются крестиком; панель выбора в сборную на `/rating` (`data-pick-bar`: «Первые 5/10», «Сбросить», счётчик).
Малые кнопки (`BTN_SM`/`BTN_OK`/`BTN_NO`) на сенсорных экранах не ниже 44 px. В кабинете федерации сверху — полоса «Быстрые действия».

## Большие списки

Общий подход для реестра, модерации заявок, журнала, календаря и ленты: фильтрация, сортировка и страницы — на сервере
(`shared/listing.py`: поиск по словам без учёта регистра и «ё», `page()`, `facets()`), состояние — в адресе (можно
поделиться ссылкой, «назад» работает).

- `gateway_service/listing_ui.py`: `qs(request, **изменения)` (глобальная функция шаблонов: текущий адрес с изменёнными
  параметрами; пустое значение убирает параметр, любой фильтр сбрасывает номер страницы), `pages(result)`,
  `list_args(request, …)`, `chips(request, filters, labels, defaults)` → чипы и адрес «сбросить всё».
- Номер страницы за последней приводит к последней странице прямо в `shared/listing.page()` (`clamp_offset`),
  поэтому маршрутам ничего досчитывать не нужно.
- Макросы: `pager(p, request)` (номера с окном, «показано 1–50 из N», размер страницы 25/50/100/200),
  `sort_th(label, key, request, sort, order)` (`aria-sort`), `filter_chips(chips, reset)`, `search_box(value, placeholder, id)`,
  `facet_option(value, label, current, facet)` — вариант фильтра со счётчиком (нули приглушены).
- Форма с массовыми действиями начинается с отключённой скрытой кнопки `submit`: Enter в текстовом поле не отправляет
  форму первой «настоящей» кнопкой (например, «Одобрить отмеченные»).
- `form[data-autosubmit]` — списки и флажки применяются сразу, поиск — через 450 мс паузы; пустые поля не попадают
  в адрес; фокус и курсор восстанавливаются после перезагрузки. «/» — к поиску, Esc — очистить.
- На телефоне поля с классом `.fsp-more` свёрнуты под кнопку «Фильтры · N» (`[data-filters-toggle]`, правило в `app.css`).
- Рядом со значением фильтра — сколько записей найдётся (фасет без собственного фильтра); значения в ячейках таблиц —
  ссылки «показать только это» (организация, муниципалитет, дисциплина, автор в журнале).
- `[data-filter-input]` — мгновенный фильтр по уже загруженному списку (рейтинг, подопечные тренера);
  `[data-option-filter]` — поиск внутри длинного `<select>` (назначение судей).
- `[data-bulk]` — массовый выбор: `[data-bulk-item]`, «все на странице» `[data-bulk-all]`, Shift — диапазон,
  счётчик `[data-bulk-count]`, кнопки `[data-bulk-action]` активны только при выборе.
- Таблицы — в контейнере `max-h-[72vh] overflow-auto` с закреплённой шапкой; панель фильтров закреплена на `lg+`.

## Особенности Jinja и Starlette

- Starlette 1.0: `templates.TemplateResponse(request, name, context)` — `request` первым аргументом.
- Макросы, которые используются внутри дочернего шаблона, должны быть определены **внутри `{% block %}`**
  (пример — `assignment()` в `cabinet_judge.html`).
- Фильтры шлюза: `ru_date` (`|ru_date`, `long=True`), `ru_mon`, `days_word`; глобальные `plural(n, …)`, `D`,
  фильтр `tojson_ru` для JSON с кириллицей.
- Тексты, на которые завязаны e2e-проверки (`DEMO_ACCOUNTS[].check`), менять только вместе с `demo_roster.py`.

## Вход и выход (аудит пути)

- Кнопка «Выйти» в шапке: иконка + подпись (на `sm+`), цель касания 44 px; после выхода — flash на главной.
- Форма регистрации без `novalidate`: браузер подсвечивает поле на месте, серверные ошибки — плашкой сверху.
- В шапке кабинета — «Подключить Telegram» / «Telegram подключён · Отключить» (`_cabinet_head.html`).
- В шапке сайта у вошедшего — колокольчик (`icon("bell")`) со счётчиком новых → `/notifications`; у федерации в меню — «Реестр».
- Основное меню шапки показывается с `xl` (1280 px), ниже — бургер: у федерации с двумя ролями шапка не помещалась в 1024 px.
