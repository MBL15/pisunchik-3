## Рекомендуемый порядок

1. **Обязательное:** закрыто, включая ленту уведомлений, реестр с фильтрами, сроки отчётов и антидопинг. Остаётся сверить с министерством пороги ЕВСК, текст проекта приказа и перечень сроков отчётов.
2. **Дополнительное:** сделано целиком (Д1–Д12), остаётся сверить рабочие справочники (пороги ФССП, размеры премий, тексты справочника) с первоисточниками.
3. **Из ревью:** загрузка файла положения (С2), учёт выбытия в численности (С8), автосмена статусов соревнований по датам (Р1).
4. Актуализировать README и `docs/knowledge-base/` после каждого пункта.
