Как подключиться

  1. Возьмите настройки из {{ issuer }}/.well-known/openid-configuration.
  2. Отправьте пользователя на /oidc/authorize: response_type=code, client_id, redirect_uri, scope=openid profile roles, state, nonce, code_challenge (S256) и code_challenge_method=S256.
  3. Обменяйте code на токены: POST /oidc/token с code_verifier, для конфиденциального клиента — с client_secret (Basic или в теле).
  4. Проверьте подпись id_token по /oidc/jwks (RS256), затем читайте /oidc/userinfo с access-токеном.
