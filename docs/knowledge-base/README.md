# База знаний · ФСП Оренбург (ОренКод 2026)

Прототип единой цифровой платформы регионального отделения Федерации спортивного программирования
Оренбургской области: реестр участников с ФСП ID, календарь, заявки, автоматические протоколы из логов,
прозрачный рейтинг сезона, справки с QR-проверкой и кабинеты для четырёх ролей.

Здесь собрано то, что нужно знать, чтобы разобраться в проекте, менять его и демонстрировать.
Источник истины — код; если статья и код расходятся, прав код, а статью нужно поправить.

## Глоссарий

| Термин | Значение |
|---|---|
| ФСП | Федерация спортивного программирования |
| ФСП ID | Региональный идентификатор участника `FSP-56-YY-NNNNN-C` |
| ЕКП | Единый календарный план Минспорта России |
| ЕВСК | Единая всероссийская спортивная классификация (разряды и звания) |
| Разряд | Спортивный разряд/звание, у большинства есть срок действия |
| Судейская категория | Квалификация судьи (ЮС, 3К, 2К, 1К, ВК) со сроком действия |
| Привязка (связь) | Отношение тренер↔спортсмен по дисциплине со статусом |
| Заявка | Заявка спортсмена на соревнование, проходит модерацию федерации |
| Протокол | Ранжированная таблица результатов, собранная из лога |
| FSP-LOG/1 | Текстовый формат лога соревнования, который понимает парсер |
| ICPC / score | Режимы ранжирования: по задачам и штрафу либо по сумме баллов жюри |
| DSQ | Дисквалификация в протоколе: участник остаётся в таблице без места |
| Санкция | Дисквалификация или отстранение участника на период; исключает из рейтинга и заявок |
| Коэффициент стабильности | Множитель ×1.2 к рейтингу за призовые места на ≥ 2 соревнованиях сезона |
| Деградация | Режим, когда сервис недоступен, а страница рендерится с `[WARN]` |
| Активная роль | Роль, в которой пользователь сейчас работает; переключается без повторного входа |
